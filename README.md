The Battleship Game is a console-based strategy game built entirely in the C programming language,designed to simulate the classic naval combat experience. 
The project focuses on logic building, array manipulation, and modular programming concepts — making it both entertaining and educational.

 The game takes place on a grid-based battlefield, where the player attempts to locate and sink enemy ships hidden across the board. Each turn allows the player (and optionally, the computer) to guess coordinates.
 The program provides immediate feedback — hit or miss — and keeps track of ship health until one side wins.
