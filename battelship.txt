1. INTRODUCTION
1.1 What is Battleship Game?
Battleship is a classic strategy game where two players try to sink each other's navy ships by guessing their locations on a grid. This is a computer version of the game that I programmed in C language.

1.2 Purpose of the Project
I created this game to learn programming concepts like:

How to use structures in C

How to handle user input

How to make the computer play intelligently

How to display graphics using text and emojis

How to add sound effects

6. GAME MODES
6.1 Player vs Computer (Mode 1)
How it works:

You place your 5 ships on your board

Computer randomly places its ships

You take turns shooting at each other's boards

First to sink all enemy ships wins!

Your Role:

Place ships manually by entering coordinates

Shoot by entering target coordinates (like "A5")

See only hits/misses on computer's board (not ship locations)

Computer's Role:

Places ships randomly

Uses smart AI to hunt your ships

Doesn't cheat - can't see your ship locations

6.2 Computer vs Computer (Mode 2)
How it works:

Both players are computer-controlled

Fully automated game for demonstration

You can watch the computers play against each other

Shows both boards so you can see all ship locations

7. SMART COMPUTER AI
7.1 How the Computer Thinks
The computer doesn't just guess randomly - it uses strategy:

Phase 1: Hunting

Shoots at random positions until it gets a hit

Phase 2: Tracking

When it hits a ship, it remembers the location

It systematically checks adjacent squares (up, down, left, right)

Continues in the direction that gets more hits

Phase 3: Sinking

Once a ship is sunk, it goes back to random hunting

7.2 Example of Computer Strategy

1. Computer shoots at B3 - 💥 HIT!
2. Now it checks around B3:
   - B4 → 💧 MISS
   - B2 → 💥 HIT! 
3. It continues direction: B1 → 💥 HIT!
4. Ship sunk! Returns to random shooting.
9. GAME FLOW - STEP BY STEP
9.1 Starting the Game

1. Program starts → Show main menu
2. Player chooses game mode
3. Initialize game structures
4. Set up boards and place ships
5. Start game timer
9.2 Player's Turn 
1. Display opponent's board (hits/misses only)
2. Ask for target coordinates
3. Validate input (check if format like "C5")
4. Process the shot:
   - If miss: Show 💧 and play miss sound
   - If hit: Show 💥 and play hit sound
   - If sunk: Show 💀 and play sunk sound
5. Update board display
6. Check if game is over
9.3 Computer's Turn

1. Computer decides where to shoot using AI
2. Process the shot automatically
3. Show results with animations
4. Update board display
5. Check if game is over
9.4 Game End

1. Stop game timer
2. Show victory message
3. Display final boards
4. Show game statistics:
   - Time taken
   - High score comparison
   - Ship status
5. Return to main menu
9. INPUT HANDLING
9.1 Coordinate Input
Players enter coordinates in "LetterNumber" format:

Valid: "A1", "G7", "C4"

Invalid: "A8" (row doesn't exist), "H1" (column doesn't exist)

9.2 Input Validation
The program checks:

Is the input format correct?

Are the coordinates within the 7x7 grid?

Has this position been shot at before?

9.3 Error Handling
If input is invalid, the program:

Shows error message

Clears the input buffer

Asks for input again
